# Cyber-Cop v35c — основная игра с Sega Mouse и отдельной тестовой картой

Сборка для проверки от 29 октября 2026 года. В GitHub пока не отправлена.

## Дополнение v35c

- Ползунок Options больше не повреждает фоновый слой: его тайлы перенесены из таблицы имён слоя B ($C800) в отдельный участок VRAM ($D400–$D51F). Короткая запись тайлов и ссылок на них защищена от VBlank.
- После выбора доступного этажа мышь блокируется на весь штатный переезд лифта: движения, клики и переключение режима не обрабатываются. Накопленный ввод отбрасывается; удержанную кнопку после прибытия нужно отпустить, прежде чем новый клик сработает. Недоступный этаж блокировку не включает. Mouse Off сохраняет штатное поведение.
- Свободный курсор при Mouse On запрещает жесты прыжка/приседания. Ходьба джойстиком сохранена; режим захвата и Mouse Off используют прежние жесты.
- При удержании кнопки уменьшения яркости Scanman у противоположной кнопки различимы и стрелка, и её внутренний прямоугольник. Отпускание точно восстанавливает исходные пиксели.
- Сохранён фикс v35b: Start запускает выбранный пункт подменю новой игры, включая скрытую тестовую карту.

Повреждение объектов кулаком и клики в меню персонажа/снаряжения в эту сборку **не добавлены**: выполнено исследование, см. RESEARCH_RU.md.

## Исправлено после первой v35

- Устранён чёрный экран при запуске. Опрос мыши в VBlank больше не захватывает и не освобождает шину Z80. Ранее он мог отменить ещё ожидающий запрос штатного звукового кода, оставив его в бесконечном ожидании `$156E4`.
- В дополнительных панелях области клика точно совпадают с прямоугольниками переворачиваемых рамок, включая сами рамки. Границы для удержания совпадают с границами нового клика. Положение графики и штатных нажатых текстур не изменено.
- Новые строки Options, ползунок и таблица зон клика размещены отдельно от готовых изображений меню сна. Все исходные варианты его изображений сохранены побайтно.
- Эта сборка проверена запуском непосредственно в BlastEm 1.0.0: с мышью и без неё, основная игра и вход на скрытую тестовую карту. CPU-тесты с упрощённой периферией первой v35 пропустили конфликт со звуковым процессором; эта граница прежней проверки теперь явно учтена.

Внутри игрового главного меню остаётся обозначение v35; исправленный файл отличается суффиксом **v35c** и контрольной суммой.

## Что изменилось после v34

В основную игру перенесены принятые изменения MouseLab Test09: драйвер Sega Mouse (вариант Direct), свободный курсор с ручным прицеливанием, вертикальное смещение обзора, мышиное управление панелями и меню сна, визуальное удержание кнопок, настройки мыши и исправления интерфейсов. Джойстик остаётся доступным.

Дополнительно:

- Подтверждённое кнопкой Enter время бомбы обозначается ярко-жёлтым индикатором. Вооружённая бомба сохраняет красный индикатор. Для жёлтого освобождён дублирующий красный цвет именно в палитре бомбы; остальные красные пиксели переназначены на его идентичный дубликат.
- При нажатии «уменьшить яркость» у Scanman стрелка противоположной кнопки остаётся различимой на затемнённом фоне.
- При Mouse On направления джойстика продолжают двигать игрока во время кликов по инвентарю. Отпускание направлений останавливает движение. Отключено только сохранение последней скорости при переходе в инвентарь — исходный «круиз-контроль». При Mouse Off исходное поведение сохранено.
- Добавлен скрытый вход на отдельную тестовую карту. Читы и Music Off на ней автоматически не включаются.
- Штатный soft reset сбрасывает временные настройки, читы, чувствительность, положение обзора и выбор тестового мира. Существующая SRAM не стирается.

## Управление мышью

Мышь Sega Mouse подключается ко второму порту. После обнаружения доступен пункт Mouse в Options, перед Exit. При Mouse On ниже появляется ползунок чувствительности; при Mouse Off он скрывается, сохраняя выбранное значение до сброса. В стартовых меню настройки выбираются джойстиком; четвёртая кнопка мыши действует как Start.

В игре средняя кнопка переключает захват обзора и свободный курсор.

| Режим | Левая кнопка | Правая кнопка |
| --- | --- | --- |
| Захват обзора | Контекстное действие A: взаимодействие, подбор, соответствующие действия перемещения | Стрельба |
| Свободный курсор над миром | Клик | Стрельба в точку прицела |
| Панель предмета/объекта | Нажать кнопку | Штатный выход из панели, как Start |
| Меню сна | Следующее значение | Предыдущее значение |

Выход из сна мышью — повторный клик по иконке сна. В интерфейсах кнопки срабатывают в момент нового клика; удержание показывает нажатое состояние, но не превращается в повторное действие или выстрел. Ремонт удерживается штатно. Перетаскивание уже зажатой кнопки на другую иконку не нажимает её. Кликающая точка стрелки — её верхний левый видимый пиксель.

В первом экране меню сна Mouse расположен под Wall Stripe, а чувствительность — следующей строкой. Ползунок можно тянуть по горизонтали; новая скорость применяется после отпускания. Mouse Off во сне временно сохраняет координаты курсора и наклон, позволяя снова включить мышь новым левым кликом. Если выйти из сна с Mouse Off, горизонт центрируется и управление становится обычным джойстиковым. При исчезновении мыши после двух неудачных VBlank-опросов включается Mouse Off.

Обзор вверх/вниз — смещение проекции и горизонта с согласованным отсечением стен и объектов, до ±100 пикселей внутреннего окна. Это не геометрический поворот камеры на заданное число градусов.

## Тестовая карта

Start New Game → Select Default Character / Create New Character. Встаньте на Create New Character и четыре раза отдельно нажмите Down. Появится третья строка **Load Test Map 01**. Список не зацикливается; другая кнопка сбрасывает счётчик. Start, как A/B/C, запускает выбранный пункт.

На карте есть комнаты, коридоры, двери, разрушаемые объекты, камеры, терминалы, Scanman и тестовый набор предметов. Коды тестовых замка и шлюза — **0451**. Лифт находится на боковой стене; служебная клетка выхода — внутри кабины. Его кнопки позволяют проверять интерфейс, но не переводят в основную игру. Подтверждение шлюза также не покидает тестовый мир. Кнопки fuse box воздействуют на освещение тестового этажа, используя штатное восстановление.

Карта имеет отдельный идентификатор мира `$0100`. Старые процедуры рендеринга получают допустимый профиль этажа 0; это адаптер для старого движка, а не возможность перехода между мирами. Загрузка любого следующего этажа внутри тестового мира снова выбирает тестовую карту.

**Запись SRAM и выдача пароля в тестовом лифте отключены до выполнения сериализации.** Поэтому случайно перезаписать сохранение основной игры или получить из тестового мира пароль основной игры нельзя. Ручные пароли и Resume Saved Game всегда выбирают основную игру. Для выхода из тестового мира используйте reset и обычное главное меню.

Бессмертие, бесконечные ресурсы и отключение музыки не навязываются. Если нужны — включите вручную в Cheats. После reset эти настройки не переносятся ни в основную игру, ни в новый запуск тестовой карты.

## Файлы и установка

- `Cyber-Cop_v35c.bin` — готовый ROM, 2 МиБ.
- `Cyber-Cop_v35c.ips` — патч для оригинального несжатого Cyber-Cop в формате BIN. Не применять поверх v34 или MouseLab.
- `Cyber-Cop_v35c_Fixes_RU.md` и `.txt` — полный русский список изменений относительно оригинала для форума.
- `TEST_RESULTS.txt` — результаты автоматических проверок и их ограничения.
- `sources/` — исходники воспроизводимой сборки; команда описана в `sources/BUILD_RU.md`.

SRAM основного прохождения сохраняет формат v34. Перед проверкой скопируйте свой файл SRAM. Начинайте через reset, новую игру, пароль или Resume Saved Game: старый эмуляторный save state содержит старые адреса кода и не предназначен для переноса между сборками.

## Проверка сборки

Выполнены тесты кода 68000, прерываний VBlank, интерфейсов, сохранения/восстановления и изоляции тестового мира. Панели визуально проверены по изображениям, построенным из игровых пикселей и палитр. Дополнительно выполнен описанный выше запуск в BlastEm. Полное прохождение, Kega Fusion и реальная приставка остаются за пользовательским тестированием.

Известная особенность исходной игры с повторным случайным определением поломки при подборе выброшенного предмета в этой версии не изменена.
