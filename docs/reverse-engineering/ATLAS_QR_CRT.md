# Самостоятельный QR ROM для ЭЛТ

64 КиБ, без данных игры, Z80 и SRAM. Сборка: python3 v36/build_qr_crt.py OUT.bin; нужна установленная libqrencode. Model 2, версия 3, M; URL https://valetos2.github.io/cyber-cop-atlas. H40 320×224, по центру, чёрный на светло-сером $CCC (палитра Original 5F). Четыре модуля поля. Start: 74 → 111 → 148 → 185 → 74 пикселя, один шаг при нажатии. В основной ROM пока не включён.

PASS BlastEm: загрузка, 3 и 6 кнопок, циклическое переключение, отсутствие повтора при удержании. Все четыре кадра BlastEm декодированы отдельно через ZBar. Физический ЭЛТ и выбранный масштаб ещё не проверены.
