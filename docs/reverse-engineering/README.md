# База знаний reverse engineering

Актуальный срез: **Genesis v36 test02, 2026-11-07**. Это индекс исследованных областей, а не полный дизассемблер игры.

| Документ | Когда читать |
|---|---|
| [Адреса](addresses.csv) | Поиск известной процедуры, таблицы или RAM-поля |
| [Архитектура и данные](ARCHITECTURE.md) | Кампании, карты, сохранения, рендер, мышь, звук |
| [Ошибки и исправления](BUGS.md) | Почему меняли конкретный перехват; что остаётся неизвестным |
| [Сборка и проверка](BUILD_AND_TEST.md) | Входные данные, точная версия, выбор минимального теста |
| [Состояние разработки](../../DEVELOPMENT_STATE.md) | Продолжение после перерыва |
| [Правила](../../AGENTS.md) | Коммиты, WIP, границы публичных материалов |

Статусы: **CONFIRMED** — подтверждено указанным исходником/исполнением; **HYPOTHESIS** — объяснение, требующее проверки; **OPEN** — нерешённый вопрос; **SUPERSEDED** — историческое сведение, опровергнутое/заменённое новым.

Порядок поиска: `rg` по этому каталогу → точный символ в `v36/*.py`, `v36/symbols.json`, `v35c/symbols.json`, `v34/symbols.json` → старые исходники `sources/` → исследовательские скрипты. Только затем локальный диапазон нужной версии ROM. Например: `rg -n '4966|original_lamps36|lift_clock36b' docs v36`.

Не переносить абсолютные адреса между платформами и сборками. Сгенерированные символы v36 относятся именно к test02; добавление кода сдвигает последующие символы. Таблица адресов перечисляет устойчивые native-адреса и выделенные RAM-поля, не заменяя symbols.json.

Исторические заметки `mission_port36/PROGRESS_RU.md` из старых приватных архивов устарели (они могут утверждать, что перенос ещё не собран). На GitHub они намеренно не скопированы. Авторитет текущего состояния: DEVELOPMENT_STATE, затем тематический документ и фактический исходник.
