# Cyber-Cop v34

Накопительный патч. Формат SRAM не менялся; атлас остаётся редакции 35.

- Если Drop стал недоступен после смены предмета, автоматический поиск идёт влево до разрешённой иконки. Предыдущий аналогичный фикс для Use сохранён. Явное перемещение курсора стрелками не перенаправляется.
- Scanman после успешного автоматического выбора Screen переводит курсор на Use. Сохраняется родной порядок Screen 1 → 2 → 3; при отсутствии записей принудительной смены выбранного предмета нет.
- Нажатие любой наружной кнопки вызова лифта сохраняет текущую позицию курсора и выбранный предмет. Убран родной принудительный перенос на ленту. В этом обработчике нет выбора ID-карты; автоподстановка карты внутри лифта и у терминалов сохранена.
- Устранена конкуренция двух отрисовщиков Energy: новая процедура показывала энергию с восстановлением, а штатный VBlank-HUD регулярно возвращал старое значение. Теперь сон только рассчитывает показание; единственная штатная процедура HUD рисует именно его. Воспроизведена последовательность v33 «456 → 200» при исходной энергии 200 и накопленной прибавке 256; в v34 показание остаётся 456. Период и формула восстановления не менялись; визуальный прогон в Fusion остаётся за игровым тестированием.
- Главное меню больше не зацикливается, включая состояние с открытыми Cheats. Четыре отдельные Down на Options по-прежнему открывают читы; дальнейшие Down оставляют курсор на Cheats.
- Ожидание бездействия в главном меню увеличено с 1250 до 2500 обновлений. Любое распознанное действие перезапускает удвоенный таймер.
- Повторное использование включённого Jet Pack выключает его. Сбрасываются удержание прыжка и приседание; обычная физика опускает персонажа до положения стоя. Отключение звука по-прежнему проверяет, что текущая последовательность принадлежит ранцу, и не прерывает сирену или музыку лифта.

## Установка

Готовый BIN можно запускать сразу. IPS применять к оригинальному Cyber-Cop, а не к предыдущей модификации. Для продолжения скопируйте SRAM под имя нового ROM, сохранив резервную копию. Fusion GST содержит старые адреса кода и может быть несовместим.

Сборка из каталога sources:

    python3 v34/build_v34.py /path/to/Cyber-Cop.bin /path/to/Corporation.bin output

SHA-256 оригинального Cyber-Cop:
98838ed8d69349ab64a99e4a4e0ea72843d47b175b69fda36957283932f0aba9

SHA-256 оригинального Corporation:
226368b1693af2db21bb1cc640b94d5b021c9ff20fcb86207d2b76590503cc98

Сборщику нужны оба ROM, для применения готового IPS — только Cyber-Cop. Данные ускоренных спрайтов генерируются из входного ROM.

## Проверки

23 сценария тестирования: исполнение процедур M68000, переходы курсора, автоопределение Screen, обе кнопки лифта, единственный отрисовщик Energy, границы главного меню, удвоенный таймер, выключение ранца и штатная последовательность спуска; также прежние проверки сохранений, управления, звуковых команд и графических процедур. Исходники из архива пересобирают ROM побайтно.

Это не полный запуск Fusion, не прослушивание YM2612 и не испытание на приставке. Результаты — TEST_RESULTS.txt, пояснения — QUESTIONS_RU.md.
