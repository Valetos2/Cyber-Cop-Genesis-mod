# Cyber-Cop — атлас 16 уровней, редакция 37

Номер редакции атласа независим от версии ROM.

## Новое в редакции 37

- В перечислении доступов группы этажей заключены в обычные квадратные скобки, названия этажей остаются жирными.
- При Ru / En сохраняются текущий этаж, масштаб, ширина правой панели, высота превью, прокрутка карты и легенды, выбранная клетка и подсветка. Состояние передаётся в адресе между двумя локальными HTML; localStorage для этого не требуется.
- Явный выбор русского не отменяется английским языком ОС, даже если локальное хранилище запрещено.

Распакуйте весь архив и откройте Cyber-Cop_Atlas.html. При первом открытии выбирается язык браузера: русский для ru, английский для остальных. Кнопки En / Ru справа от масштаба позволяют изменить выбор; если браузер разрешает localStorage для локальных файлов, выбор сохраняется. Это определение языка браузера, а не геолокация или прямое чтение региона Windows. Английский файл можно открыть сразу: Cyber-Cop_Atlas_en.html. Изображения встроены; интернет не нужен. Для переключения языка оба HTML должны лежать рядом.

## Новое в редакции 35

- На панелях замков показаны исходные коды соответствующего этажа; на шлюзе — 9831. Это исходные значения, не код текущей рандомизированной сессии. Цифры выводит родная процедура $9956.
- Превью терминалов показывают доступ для примерного маршрута 5F → 4F → Parking → L2 → L7 → L5 → 3F → L4. Реальная игра повышает текущий доступ на единицу за первый терминал на новом этаже, до максимума 7. Другой порядок посещения даёт другие промежуточные значения.
- Терминалы мигают два раза в секунду на карте и в легенде. Перерисовываются только клетки терминалов; выбранная клетка и прокрутка легенды сохраняются.
- Серая вертикальная ручка у правой панели меняет её ширину. Горизонтальная ручка под превью меняет его высоту. Можно также выделить ручку клавишей Tab и использовать стрелки. Изображения масштабируются с сохранением пропорций.
- Появление игрока на 5F отмечено P (X6 Y6). Для Parking и Warehouse добавлены ориентиры прибытия через шлюзы. В отличие от фиксированного спасения R на L4, шлюз преобразует текущие координаты игрока: отмечены примеры при использовании из центра клетки пульта, а не единственные возможные точки.
- Описание каждого шлюза указывает этаж назначения и пример координат. Перед первой группой доступов добавлен отступ; группы разделены точками с запятой, последняя закончена точкой.

## Сохранено из предыдущей редакции

- Двери: прежняя промежуточная высота камеры 270, расстояние шесть клеток; полоска и дизеринг отключены. Обычная палитра 5F.
- Панели обрезаны по полезной графике. Чёрный фон, соединённый с краями картинки, прозрачен; внутренние чёрные области сохранены. Скругления не оставляют чёрных углов.
- Screen 1–3 содержат только запись 80×48 пикселей, накладываемую внутри Scanman. Сам Scanman показан целиком.
- Луч: три соседние клетки, камера напротив средней в восьми клетках, поднята до 220 мировых единиц. Геометрия рассчитана игровыми процедурами; для статического превью трёх сегментов выбраны светлые фазы родной палитры Visor 1. Захваченные четырёхугольники закрашены программно. Это иллюстрация игровой геометрии, не скриншот одной неизменённой игровой сцены.
- Объект и его панель получают равные половины области предпросмотра, сохраняя пропорции; широкий интерфейс больше не уменьшает объект до крошечной иконки.
- Русский и английский интерфейсы, раздельные группы справки «доступ — этажи».

## Использование

Щелчок по клетке закрепляет сведения. Щелчок вне карты и её панелей снимает выделение. Пункт легенды выделяет все клетки такого типа; повторный щелчок выключает выделение. Пол/стены не подсвечиваются. Исходные враги стоят первыми в легенде; S обозначает точки повторного появления $0E. Описание и превью закреплены, легенда прокручивается отдельно. Кнопки рядом с этажом переключают карты без зацикливания.

Изображения врагов показаны спереди в обычной палитре этажа; предметы — иконками рюкзака. Камера: кадр 5, детектор: 14, проектор: 121, кресло: 180, ящик: 129 (THIS WAY UP). Это оригинальные ракурсы, без зеркального отражения.

Обычные замки помечены как случайные для новой игры v26+. Атлас показывает исходные коды, а не содержимое вашего SRAM. Нынешняя процедура делает восемь обменов в таблице, поэтому отдельный код, в том числе 9732 на 4F, может не измениться. Шлюз сохраняет код 9831. Parking требует embryo; R на L4 отмечает спасение с Bomb. Подробности — QUESTIONS_RU.md.

## Содержимое и проверки

Два HTML, 16 PNG-карт, sprites, data.json, cells.csv (64 000 клеток), исходники и журнал проверок. Тексты внутри оригинальных игровых изображений не переводились. Редактор языка меняет интерфейс и пояснения HTML; отдельные исследовательские заметки и подписи PNG-карт остаются русскими.

Проверены JavaScript-обработчики с моделью DOM, все этажи/типы клеток, переключение языка, равенство данных RU/EN, границы прозрачности изображений. Изображения просмотрены. Полного визуального браузерного прогона не было. Исходники в sources/atlas36 — исследовательские инструменты с зависимостями от локальных ROM/GST и прежних сборок, не самостоятельный пакет генератора. Готовым HTML они не нужны.

Использованы оригинальные карты, спрайты, графика и палитры Corporation / Cyber-Cop. Разработчики и исторические издательские титры приведены в отдельном блоке интерфейса; права на ресурсы остаются у соответствующих правообладателей. Неофициальный атлас не связан с ними.
