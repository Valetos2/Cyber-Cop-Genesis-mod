# Сборка v35c

Нужен Python 3; внешние Python-пакеты и отдельный ассемблер для сборки не требуются.

```
python3 build_v35.py "/путь/Cyber-Cop.bin" "/путь/Corporation.bin" "/путь/результат"
```

Входные файлы — несжатые оригинальные дампы BIN:

- Cyber-Cop: SHA-256 `98838ed8d69349ab64a99e4a4e0ea72843d47b175b69fda36957283932f0aba9`.
- Corporation: SHA-256 `226368b1693af2db21bb1cc640b94d5b021c9ff20fcb86207d2b76590503cc98`.

Оригинальные ROM не входят в исходный комплект. Corporation нужен прежней части модификации, использующей его титульную графику. Для применения уже готового IPS нужен только оригинальный Cyber-Cop.

Сборщик последовательно воспроизводит базовую v34, Direct-драйвер MouseLab и интеграцию v35c во временной папке. Результат: BIN, IPS и таблица адресов symbols.json. Промежуточные экспериментальные ROM в итоговую папку не копируются.

`v35/boot_vram.bin` — вспомогательный снимок VRAM, используемый генератором графики кнопок; `v34/easter_tiles.bin` — сохранённые авторские тайлы Valet2. Это необходимые бинарные входы текущего сборщика, а не дополнительные полные игровые ROM.

Автоматические проверки выполнялись отдельно с Unicorn 2.1.4, Capstone и Pillow, игровыми дампами состояния и предыдущими версиями для сравнений. Эти исторические тестовые данные не входят в минимальный комплект сборки; сводка проверок находится в TEST_RESULTS.txt основного архива.
