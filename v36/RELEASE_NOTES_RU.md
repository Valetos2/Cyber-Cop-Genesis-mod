# Cyber-Cop v36

Выпуск от 9 ноября 2026 года (Москва). Основа — v35c; ROM 4 MiB.

## Последние исправления

- Красный индикатор запрещённого этажа в лифте получил тень и блик, как индикаторы других терминалов.
- При вызове неправильной кнопкой лифт едет до крайнего этажа, стоит там ещё один межэтажный интервал (80 VBlank), затем возвращается: например, L6 → L7 → L8 → L8 → L7 → L6 → L5. Обычный вызов и ожидание на текущем этаже не изменены.
- Выброшенный сломанный предмет сохраняет поломку при подборе и уходе с этажа с возвращением. Исправные предметы по-прежнему могут оказаться сломанными после выброса и подбора. Технически штатная случайная проверка выполняется при подборе; уже сломанные предметы теперь её пропускают.
- В главном меню отображается v36.

**Не исправлено:** скачок курсора к верхнему краю в Kega Fusion. На предоставленном сохранении в BlastEm не воспроизведён ни при инъекции неподвижных кликов, ни при кликах через штатный опрос мыши. Причина не установлена; это не объявляется ни исправлением, ни доказанным багом эмулятора.

## Основные изменения относительно v35c

- Вторая кампания Amiga Mission Disk: 16 карт, начальные враги, предметы, появление врагов, права доступа, тюрьма и особое событие тревоги. Карты оригинальной кампании Genesis сохранены.
- Независимые продолжения и SRAM двух кампаний; пароль выбирает нужную кампанию. Continue появляется только при наличии соответствующего сохранения. Читы общие для сеанса, Reset сбрасывает временные настройки.
- Новые бочка, стулья и их обломки; двуногий робот с движением, атакой и смертью. Два звука робота добавлены в Sound Test (24 — шаг, 25 — атака). Перенесены отличающиеся изображения Scanman и финальное изображение/текст Mission Disk. Финальные титры Genesis и наш блок сохранены.
- Светильники потолка и пятна на полу; в оригинальные карты они добавлены только в проверенные пустые клетки. Lamps on/off в Options и меню сна. Эллипсы больше не чередуются с одной строкой и не имеют вертикальных игл. Таблицы ускоряют отрисовку крупных эллипсов.
- Исправлены серые полосы пола/потолка Mission, нижние полоски импортированных спрайтов, столкновения выстрелов с новой бочкой. Новая бочка неразрушаемая, как в Amiga. Обе бочки визуально опущены одинаково, с масштабированием смещения по расстоянию.
- Мемориальный экран Кевина Балмера с Amiga-портретом перед SEGA. Исправлены стартовая вспышка и смещение при повторном показе.
- Мышь в выборе персонажа/снаряжения: точные области кнопок, один курсор, визуальное удержание без повтора. ПКМ не листает предметы; четвёртая кнопка подтверждает выбор. В снаряжении показывается портрет; убран ложный звук при входе.
- Ограничен выбор лишних копий устройств; дроиду не предлагаются First aid и ненужные маски. Electronics остаётся доступной людям для бионики.
- Test map 01 восстановлена; test map 02 использует ресурсы Mission. Обе карты изолированы от SRAM кампаний. Скрытый запуск: create new character, ещё четыре Down; следующий Down выбирает test map 02. A/B/C/Start запускают выбранный пункт.
- Лифты обеих кампаний используют штатный интервал 80 VBlank. Исправлены бесконечные поездки. Выбор разрешённого этажа сохраняет SRAM с этажом назначения; переходы Parking/Warehouse не добавляют сохранений. Новые клики во время вызова не меняют маршрут; вторая кнопка даёт лишь визуальный отклик.
- Scanman: reset сбрасывает и изображение, и яркость; повторный вход возвращает умолчания. Исправлены полутона кнопки яркости, подписи Holo. a/b/c и удерживаемая рамка кнопки шлюза. Добавлен шейдинг индикаторам замка, шлюза и бомбы.
- После закрытия терминала восстанавливается панель инвентаря. Сон останавливает ремонт и отпускает его кнопку. Слово card сдвинуто на символ влево.
- Тревога длится впятеро дольше. Автоприцел предпочитает ходящих врагов и крабовую голограмму, затем камеры; аварийные лампы имеют низший приоритет. За стеной допускаются только ходящие враги в пределах одной клетки по глубине. Свободный курсор не использует этот автоприцел.
- Код шлюза Mission 8652 остаётся фиксированным. Два терминала одного этажа дают только одно повышение допуска, как в Amiga.

## Установка

В архиве готовый Cyber-Cop_v36.bin и два альтернативных IPS:
- Original_Cyber-Cop_to_v36.ips — для исходного Cyber-Cop (W) [c][!], без copier header.
- v35c_to_v36.ips — только для нашей точной v35c.

Применять один подходящий патч, не оба подряд. Точные размеры и SHA256 баз/результата — CHECKSUMS.txt. Для Corporation (E), другой ревизии или уже изменённого ROM первый IPS не предназначен. Оба патча проверены обратным применением с побайтовым сравнением результата.

Предпочтителен обычный запуск новой сборки. Старые savestate содержат адреса кода и временное состояние предыдущей версии; совместимость каждого такого состояния не гарантируется. SRAM и пароли проверены отдельно для обеих кампаний.

## Проверки и ограничения

18 CPU-наборов прошли: core, actors, transitions, frontend_mouse, fixes02, menu02, graphics02, cosmetics03, lights03, light_options03, lift03, aim04, sram, save04, fixes04, fixes05, items06, item_render06. Включены 392 маршрута вызова, 52 выброса и 52 подбора, сохранение предметов этажей обеих кампаний и сравнение всех 26 спрайтов подбираемых предметов с флагом поломки и без него. Индикатор лифта меняет ровно 20 пикселей линзы. BlastEm запускает сборку до главного меню; номер версии проверен также исполнением процедуры меню.

Полное прохождение новой версии и настоящая приставка не проверены. Открыты скачок курсора Kega и прежняя нестабильная ближняя геометрия gs2 при положении игрока внутри стены. Точное сравнение цвета embryo с Amiga остаётся исследовательским вопросом.

GitHub содержит авторские исходники и документацию; ROM, сохранения и извлечённые коммерческие ресурсы туда не загружаются. Материалы продолжения в rebuild предназначены для частного использования.
