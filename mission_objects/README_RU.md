# Amiga Mission Disk — исследование предметов и двуногого робота

Этот каталог содержит восстановленные из архива v36 **авторские Python-скрипты**, позволяющие извлекать и сравнивать объекты Mission Disk: бочку ($9C), два варианта стула ($9D/$9E) и кадры двуногого робота. В составе проекта сохранены инструменты, но **не распространяются** оригинальный код игры, дисковые образы, готовые листы спрайтов и извлечённая графика.

Для использования из корня локальной копии проекта требуются собственные игровые входные данные:

- amiga3/mission.bin — исследовательский распакованный образ программы Amiga;
- amiga_research/mission.adf — декодированный образ диска;
- Python 3 и Pillow.

Запуск из корня проекта: сначала python mission_objects/extract.py, затем python mission_objects/render.py. Инструменты сохраняют PNG в каталог mission_objects/. Последний скрипт использует системный шрифт DejaVu Sans по пути Linux; на Windows потребуется указать подходящий установленный TTF.

Сведения об объектах из архива: бочка 9C использует ресурс 21; стул 9D — ресурс 21; стул 9E — ресурс 18. Стулья отличаются не только палитрой, но и пикселями изображения. В Mission используется особая схема выбора ресурсов и палитр по этажу. Рисунки робота представлены отдельными анимационными кадрами, которые были адаптированы для Genesis в v36.

Выполнение этих скриптов не проверялось здесь на реальных дисковых образах; проверены только наличие исходников и корректность синтаксиса Python.
