# Проверка перед публикацией

Из корня обычного Git checkout один раз включить локальный hook:

```sh
git config core.hooksPath .githooks
chmod +x .githooks/pre-commit
```

Стадировать только нужные пути, затем:

```sh
python3 tools/test_publication.py
python3 tools/check_publication.py
git diff --cached --stat
git diff --cached
```

Hook проверяет текущую ветку wip и только staged-файлы. Не читает ROM, не запускает игровые тесты, не сканирует всю историю. Проверяет содержимое индекса, а не изменившийся после staging рабочий файл.

Для загрузки через GitHub API подготовить отдельный каталог только из предлагаемых файлов и запустить `python3 tools/check_publication.py --directory PATH`. Затем создать commit/tree от актуального wip, обновить ref с expected_sha и проверить удалённый HEAD. API не запускает локальный Git hook, поэтому этот шаг обязателен вручную.

Ограничения: это защита от случайного попадания типичных игровых файлов, не универсальный детектор copyright/секретов. Просмотр diff обязателен. Правила не отменяют существующие права на исходную игру. Нельзя маскировать ресурс переименованием в .py или .txt.
