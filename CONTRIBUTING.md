# Contributing to Cyber-Cop Genesis Mod

Thank you for your interest in improving Cyber-Cop / Corporation for the Sega Genesis / Mega Drive!

This is an independent, community-driven project dedicated to fixing bugs, improving gameplay, and developing tools for exploring and modifying the original game.

Contributions of all kinds are welcome.

## 1. What you can contribute

You are welcome to:

- Fix bugs and improve existing game modifications.
- Develop new gameplay improvements and optional features.
- Improve Python scripts, JSON data, and development tools.
- Extend the HTML-based level viewer.
- Report bugs, test patches, and suggest improvements.
- Improve documentation and translations.

Please try to keep changes understandable, documented, and compatible with the existing project whenever possible.

## 2. Submitting changes

If you would like your improvements to be included in the main project:

1. Fork the repository.
2. Make your changes in a separate branch.
3. Test your changes using the appropriate original game version.
4. Submit a pull request describing what you changed and why.

For major gameplay modifications or architectural changes, consider opening an issue first to discuss your ideas.

Please mention any known limitations, compatibility issues, or changes to the original gameplay.

## 3. Original game content

Corporation / Cyber-Cop is a commercial game created and published by third parties.

This project does not claim ownership of the original game's code, graphics, music, sound effects, or other copyrighted assets.

When contributing:

- Do not upload original or modified commercial game ROMs.
- Prefer distributing modifications as IPS patches or reproducible patching scripts.
- Do not include copyrighted third-party assets without appropriate permission or another valid legal basis.
- Be careful when contributing extracted game data, including level layouts, graphics, and other resources. Converting such material into JSON or another format does not automatically make it freely redistributable.
- Keep modifications reproducible using a separately obtained copy of the original game whenever possible.

The original game's historical development and publishing credits are acknowledged separately from the contributors to this project.
