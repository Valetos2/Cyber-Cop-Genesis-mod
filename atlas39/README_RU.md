# Cyber-Cop Atlas 40 — Original game + Mission Disk

Распакуйте оба HTML рядом и откройте Cyber-Cop_Atlas.html (Ru) или Cyber-Cop_Atlas_en.html (En). Всё необходимое встроено, интернет не требуется.

- 32 карты, извлечённые из v36 test04: исходная Genesis-кампания с добавленными светильниками и отдельная Mission Disk.
- Кнопки Original game / Mission Disk справа от стрелок сохраняют выбранный индекс этажа, масштаб, прокрутку, ширину панели и высоту превью. Ru/En передаёт также выбранную кампанию.
- Легенда доступа переключается с кампанией. Parking/Warehouse остаются отдельными переходами; точка спасения Original находится на L4, Mission — на L3.
- Коды обычных дверей показаны как исходные значения: в новой игре они рандомизируются. Фиксированный шлюз Original9831, Mission8652. Это атлас ROM-порта, а не неизменённых амижных дискет.
- Враги — алые треугольники. Камеры — красные круги, тревожные лампы — оранжевые. Светильники — контуры клеток; превью получено настоящим рендерером v36.
- Предметы имеют контрастную центральную точку. Disruptor, отмычки, маски и предметы, встречающиеся не более трёх раз в выбранной кампании, отмечены красной точкой. Капсула с эмбрионом ($96) отмечена зелёным кругом внутри квадрата с сохранённой надписью.
- У обычных предметов разные цветные точки: refill чёрный; first aid белый; electronics коричневый; narcotics розовый; chemicals бирюзовый; grenade фиолетовый; power pack синий; stun bomb светло-голубой.
- Контуры светильников затемнены; камеры и аварийные лампы затемнены на15%. Терминал шлюза мигает с периодом вшестеро медленнее обычного терминала.
- Превью светильника без вертикальных шипов также находится в sprites/scenes/2.png. В HTML оно встроено в тот же раздел scenes.
- Превью Mission используют её палитры, стулья, бочку, робота, изображения Scanman и панель шлюза8652. Терминал Mission показан с примерным начальным допуском, а не как обещание получить конкретный допуск на этом этаже.
- JSON и CSV приложены для самостоятельной работы с картами. Данные и игровые изображения не отправляются в GitHub; там остаются только исходники построения атласа.

Проверено: обе языковые версии выполняют JS без ошибок на32картах; каждая категория и начальный враг открывают описание/превью; переходы между кампаниями и языками сохраняют параметры просмотра. Автоматическая проверка DOM выполнена тестовым окружением; полноценный интерактивный прогон в браузере в этом окружении недоступен.

Оригинальные ресурсы Corporation/Cyber-Cop принадлежат их правообладателям. Неофициальный атлас подготовлен по запросу Valentin «Valet2» Kozin, 2026.

Atlas40: легенда упорядочена по игровым задачам; сигнальная лампа сразу после камеры. Шлюз меняет состояние каждые 1500 мс (полный цикл 3 с). Полный пакет содержит все превью в sprites/original и sprites/mission, а общий каталог сцен — sprites/scenes. HTML остаются автономными.


## Где находятся исходники и готовый атлас

Полный Atlas 40 — **самостоятельный ZIP-пакет**: два автономных HTML, README, JSON, CSV и 984 PNG. В GitHub оставлены авторские скрипты `atlas39/` и необходимые им исходники предыдущего генератора `atlas37/`. Устаревшие готовые файлы Atlas r37 и промежуточные каталоги `atlas35/` и `atlas38/` убраны из текущего дерева; исторические версии доступны через Git history. Проверочные скриншоты проекта сохранены.
