# Cyber-Cop Atlas 41 — Original game + Mission Disk

Распакуйте оба HTML рядом и откройте Cyber-Cop_Atlas.html (Ru) или Cyber-Cop_Atlas_en.html (En). Всё необходимое встроено, интернет не требуется.

- 32 карты, извлечённые из v37: исходная Genesis-кампания с добавленными светильниками и отдельная Mission Disk.
- Легенда показывает количество экземпляров каждого подбираемого предмета и их общее число на этаже. Подсчёт идёт по начальной карте, без учёта SRAM игрока.
- Если в одной клетке стоят и объект, и враг, карта показывает оба маркера, а панель — отдельные превью. Например, Mission L4 (30,10), Original L8 (36,18) и L6 (7,43).
- Добавлены из v37: Screen 1 на 5F Mission (15,39), Medi Kit на L3 Original (76,46) и L8 Mission (3,3), Face Mask и Gas Mask в Warehouse Mission (21,34) и (30,48).
- Сцена лазера обновлена: ракурс из проверки v37 в обычной палитре, без красного фильтра. Файл — sprites/scenes/11.png.
- Кнопки Original game / Mission Disk справа от стрелок сохраняют выбранный индекс этажа, масштаб, прокрутку, ширину панели и высоту превью. Ru/En передаёт также выбранную кампанию.
- Легенда доступа переключается с кампанией. Parking/Warehouse остаются отдельными переходами; точка спасения Original находится на L4, Mission — на L3.
- Коды обычных дверей показаны как исходные значения: в новой игре они рандомизируются. Фиксированный шлюз Original 9831, Mission 8652. Это атлас ROM-порта, а не неизменённых амижных дискет.
- Враги — алые треугольники. Камеры — красные круги, тревожные лампы — оранжевые. Светильники — контуры клеток; превью получено настоящим рендерером v37.
- Предметы имеют контрастную центральную точку. Disruptor, отмычки, маски и предметы, встречающиеся не более трёх раз в выбранной кампании, отмечены красной точкой. Капсула с эмбрионом ($96) отмечена зелёным кругом внутри квадрата с сохранённой надписью.
- У обычных предметов разные цветные точки: refill чёрный; first aid белый; electronics коричневый; narcotics розовый; chemicals бирюзовый; grenade фиолетовый; power pack синий; stun bomb светло-голубой.
- Контуры светильников затемнены; камеры и аварийные лампы затемнены на15%. Терминал шлюза мигает с периодом вшестеро медленнее обычного терминала.
- Превью светильника без вертикальных шипов также находится в sprites/scenes/2.png. В HTML оно встроено в тот же раздел scenes.
- Превью Mission используют её палитры, стулья, бочку, робота, изображения Scanman и панель шлюза 8652. Терминал Mission показан с примерным начальным допуском, а не как обещание получить конкретный допуск на этом этаже.
- JSON и CSV приложены для самостоятельной работы с картами. Данные и игровые изображения не отправляются в GitHub; там остаются только исходники построения атласа.

Проверено: обе языковые версии выполняют JS без ошибок на 32 картах; проверены все пять новых предметов, счётчики, три совмещённые клетки и сохранение вида при смене кампании или языка. Автоматическая проверка DOM выполнена тестовым окружением; полноценный интерактивный прогон в браузере в этом окружении недоступен.

Оригинальные ресурсы Corporation/Cyber-Cop принадлежат их правообладателям. Неофициальный атлас подготовлен по запросу Valentin «Valet2» Kozin, 2026.

Сохранено из Atlas 40: легенда упорядочена по игровым задачам; сигнальная лампа сразу после камеры. Шлюз меняет состояние каждые 1500 мс (полный цикл 3 с). Полный пакет содержит все превью в sprites/original и sprites/mission, а общий каталог сцен — sprites/scenes. HTML остаются автономными.

## Пересборка

Из корня рабочего проекта после сборки v37: `python atlas39/build_data.py` (для ракурса луча требуется локальный Fusion save отсюда: `upload/Cyber-Cop_v36a.gs9`, можно передать путь первым аргументом), `python atlas39/render_panels.py`, `python atlas39/build_page.py`, `python atlas39/translate.py`, `node atlas39/test_ui.js`, `python atlas39/package_full.py`. Для первых двух шагов нужны локальные игровые входы и Unicorn/Pillow; savestate не входит в пакет.
