# v36b test06 — допуск при Continue, Start и горячие клавиши

17 ноября 2026. На test05 воспроизведено: терминал 5F даёт допуск 1, поездка сохраняет 4F и допуск 1, но после холодного Continue терминал 4F не повышает допуск. Причина: $92AE копирует флаг текущего этажа ($216E) в bit 2 строки пароля, $1232 его восстанавливает. Запись из лифта временно подменяла номер этажа, но не флаг. При обычной поездке $4832 сбрасывает флаг; подтверждены обходы 4F → 5F → 4F и 4F → 4F. Теперь запись вычисляет флаг из истории этажа назначения ($2718 + номер этажа); загрузка с действительным X21 чинит флаг и в старом SRAM. Идентификаторы сохранений и ручной ввод пароля без X21 не менялись.

Mouse On: Start вызывает штатный вход $6FB2 из обычной игры (включая полосу инвентаря), открывает меню сразу, ожидание нового нажатия предотвращает мгновенный выход при удержании. Mode и закрытие полноэкранных панелей остались штатными. При Mouse Off X/Z листают инвентарь, Y выполняет Use; если до нажатия игрок был в управлении персонажем, открытие панели не включает режим управления инвентарём. Нативный автоподбор расходника сохранён.

## Ограничения и открытые вопросы
- Число инструкций CPU не равно числу тактов или FPS. В начальном кадре test02.gs0 лампы дают около 3,4% инструкций. Для крупных частично невидимых эллипсов таблицы сокращают затраты примерно на 38–58%; для малых выигрыш не гарантирован.
- Новая бочка намеренно неразрушаемая в Amiga. Стулья имеют обломки 5D/5E.
- Mission: отдельное финальное изображение и текст уже перенесены. После Amiga 5398/5410 нет дополнительной прокрутки титров: игра возвращается на 46A4. Genesis credits и mod appendix сохранены.
- HUD-01: восстановление панели после закрытия терминала устраняет артефакт, но первичный писатель 0220 в EA3C не найден. Возвращаться к исследованию только при новом воспроизведении.
